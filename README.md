# One Word, One Username, One Reward

Entry for the make.fun bounty "One Word, One Username, One Reward".
The program writes exactly one line to `/output/entry.txt`: the entrant's
make.fun username, `jepehhh`, followed by a single newline — no labels,
no explanation, nothing else (8 bytes total).
It creates the `/output` directory if missing and exits with code 0.
Run it with `node main.ts` (Node 22+).
No npm dependencies and no package.json — only the Node standard library.
